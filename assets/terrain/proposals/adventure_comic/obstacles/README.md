# Propuestas de obstáculos: cómic de aventura

Cinco sprites frontales aislados, con fondo transparente y formato cuadrado de 250 × 250 px. Se generaron con ImageGen y se redujeron desde sus originales de 1254 × 1254 px con remuestreo de alta calidad. Son propuestas de arte y no sustituyen ni están conectadas a los obstáculos activos.

| Archivo | Contenido |
|---|---|
| `crystal_blue_comic.png` | Racimo de tres cristales azules brillantes. |
| `large_rock_comic.png` | Roca grande gris de silueta simple, con grietas y un poco de musgo. |
| `bone_spikes_comic.png` | Tres pinchos de hueso y una calavera pequeña, sin gore. |
| `poison_grass_comic.png` | Hierba verde venenosa con puntas lima y gotas tóxicas. |
| `totem_comic.png` | Tótem de madera con tres caras y bandas turquesa y coral. |

El conjunto usa contornos oscuros, colores planos y formas legibles a tamaño reducido. Para adoptarlo habría que elegir los diseños y actualizar las referencias de runtime y la documentación activa.
